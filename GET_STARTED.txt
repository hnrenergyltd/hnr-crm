HNR ENERGY SOLUTIONS CRM - GET STARTED
================================================================================

IMPORTANT: Read this carefully. It has everything you need.

================================================================================
WHAT YOU'RE ABOUT TO DO
================================================================================

1. Copy all the CRM code from the folder I created into your GitHub repository
2. Install the software dependencies (Node.js packages)
3. Start the CRM on your computer
4. Open it in your web browser
5. Login and explore

Estimated time: 10-15 minutes

================================================================================
BEFORE YOU START
================================================================================

✓ You need Node.js installed on your computer
  - Go to: https://nodejs.org/
  - Download the LTS (Long Term Support) version
  - Install it (just click Next a few times)
  - Restart your computer after installing

✓ You need Git installed (probably already have it)
  - Windows: https://git-scm.com/download/win
  - Mac: https://git-scm.com/download/mac
  - Linux: comes with most distributions

================================================================================
STEP 1: CLONE YOUR GITHUB REPOSITORY
================================================================================

Open Terminal (Mac/Linux) or Command Prompt (Windows) and run:

    git clone https://github.com/ecommercewithhassan123-rgb/HNR-CRM-.git
    cd HNR-CRM

This downloads your empty GitHub repository to your computer.

================================================================================
STEP 2: COPY THE CRM CODE
================================================================================

I've created all the CRM code in a folder. You need to copy the files.

THE FILES ARE IN: /mnt/user-data/outputs/HNR-CRM-setup/

COPY THESE FILES TO YOUR HNR-CRM FOLDER:
  ✓ backend/ folder (entire folder)
  ✓ frontend/ folder (entire folder)
  ✓ package.json (root file)
  ✓ .gitignore
  ✓ README.md
  ✓ QUICK_START.md

Your HNR-CRM folder should now look like:
    HNR-CRM/
    ├── frontend/
    ├── backend/
    ├── package.json
    ├── README.md
    └── ...

================================================================================
STEP 3: INSTALL DEPENDENCIES
================================================================================

In your Terminal/Command Prompt (in the HNR-CRM folder), run:

    npm run install-all

This downloads ~1000 small files. It will take 3-5 minutes.
You'll see lots of text - that's normal. Don't interrupt it.

Wait for it to finish. You'll see:
    up to date, audited X packages

================================================================================
STEP 4: START THE CRM
================================================================================

Still in Terminal/Command Prompt, run:

    npm start

You'll see messages like:
    ✓ Compiled successfully
    Webpack compiled...

Then your browser will automatically open.

If it doesn't open automatically, go to:
    http://localhost:3000

================================================================================
TROUBLESHOOTING
================================================================================

Q: Port 3000 already in use?
A: Close other applications. Or run:
   npx kill-port 3000

Q: npm not found?
A: Node.js didn't install properly. Restart your computer and try again.

Q: Dependencies won't install?
A: Run: npm cache clean --force
   Then: npm run install-all

Q: Can't see the browser window?
A: Open http://localhost:3000 manually

Q: Want to reset?
A: Delete backend/crm.db and restart
